О NYX BROWSER

Не просто окно
в интернет. Твой стиль.

NYX Browser — независимый проект браузера для Windows. Мы хотим создать приятную среду для повседневного просмотра сайтов: с цельным дизайном, понятным управлением и функциями, которые проходят путь от идеи до работающей реализации.

Проект находится в разработке. Состав функций, требования и доступность загрузки будут уточняться вместе с релизами.

NYX / МОБИЛЬНЫЙ ДОСТУП

NYX на телефоне
сайт уже можно установить.

Мобильная версия сайта адаптирована для сенсорного управления. Добавь её на главный экран — она будет открываться в отдельном окне. Это веб-версия сайта, а не нативный мобильный браузер.

◈

Android

Открой сайт в Chrome. В меню браузера выбери «Установить приложение» или «Добавить на главный экран». Если появится кнопка установки ниже, можно воспользоваться ею.

Открой меню Chrome (⋮) → «Установить приложение» или «Добавить на главный экран».

▣

iPhone

Открой сайт в Safari, нажми «Поделиться» и выбери «На экран Домой». Подтверди добавление — ярлык NYX появится рядом с приложениями.

На iPhone установка выполняется через меню Safari.
✦

Полноценный браузер

Отдельные приложения NYX для Android (APK) и iPhone (iOS) ещё не выпущены. Мы не предлагаем скачивать APK со сторонних сайтов. Ссылки появятся только после сборки и проверки официальных приложений.

Мобильное пространство NYX

Виджеты, быстрые ярлыки, заметки, задачи, калькуляторы и встроенная мини-аркада. Это отдельная PWA-компаньон, а не полноценный браузер.

ВОПРОСЫ И ОТВЕТЫ

Есть вопросы?

Коротко о текущем состоянии проекта.

Что такое NYX Browser?＋

NYX Browser — независимый браузерный проект, ориентированный прежде всего на Windows и развитие удобного тёмного интерфейса.

Где скачать браузер?＋

Публичная ссылка на установщик пока не опубликована. Когда сборка будет готова, здесь появятся прямая ссылка, версия и системные требования.

Какие функции уже доступны?＋

Состав возможностей зависит от конкретной сборки. Этот сайт не считает функции готовыми только потому, что они запланированы. Проверяй описание и заметки к релизу.

Поддерживаются ли macOS, Linux или телефон?＋

Сайт NYX адаптирован для телефонов и может устанавливаться как веб-приложение. Отдельные приложения для Android и iPhone пока не выпущены.

Как сообщить об ошибке или предложить идею?＋

Открой репозиторий GitHub и создай issue с описанием проблемы или предложения.

ПРОЗРАЧНОСТЬ

Политика приватности.

Этот сайт является информационной страницей проекта NYX Browser. На момент публикации сайт не содержит форм регистрации, личного кабинета или собственного механизма сбора паролей.

Для загрузки шрифтов используется Google Fonts; при обращении к внешним сайтам, включая GitHub, действуют их собственные политики приватности. Хостинг Cloudflare Pages может обрабатывать технические данные запросов в рамках работы сервиса.

Если на сайте появятся аналитика, формы или другие инструменты обработки данных, эта политика будет обновлена до их включения. Вопросы по сайту можно направить через GitHub Issues.

Рекламные блоки пока отключены. Если NYX подключит рекламную сеть, до запуска будут опубликованы сведения о поставщиках, технологиях cookies и способах управления согласием. Для персонализированной рекламы посетителям из ЕЭЗ, Великобритании и Швейцарии будет использоваться сертифицированная Google CMP с поддержкой IAB TCF.
